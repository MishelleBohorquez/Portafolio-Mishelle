Soy **Ingeniera de Sistemas y Computación** apasionada por transformar necesidades reales en soluciones de software funcionales y atractivas. Mi enfoque abarca el desarrollo **Full Stack**, cuidando tanto la experiencia e interfaz de usuario como la robustez de la lógica y la arquitectura del servidor.

## 🚀 Proyectos Destacados

### 1. 🐾 Huellitas Hotel
Plataforma web integral de reservas para mascotas, optimizando la gestión de peluquería, estadía y servicios afines en un solo flujo de agendamiento unificado.
* **Tecnologías:** Java, Spring Boot, JavaScript, HTML, CSS, PostgreSQL, Postman.
* **Enlace:** [Ver Proyecto en Vivo](https://samuelvelez-g.github.io/Huellitas-Hotel-Project/)

### 2. 🎮 ENPIX
Videojuego educativo 2D enfocado en el aprendizaje de un nuevo idioma, diseñado específicamente para niños y niñas en escuelas rurales bajo el modelo de Escuela Nueva.
* **Tecnologías:** Godot, Python, PostgreSQL, Supabase, JavaScript, HTML, CSS.
* **Enlace:** [Repositorio en GitHub](https://github.com/MishelleBohorquez/VideojuegoEducativo)

### 3. 🛍️ Happy Break
Catálogo e-commerce interactivo que permite al usuario armar su carrito de compras y enviarlo directamente estructurado a WhatsApp, agilizando el proceso de pedidos sin fricciones de pagos en línea iniciales.
* **Tecnologías:** JavaScript, HTML, CSS, Python.
* **Enlace:** [Ver Proyecto en Vivo](https://catalogo-happy-break.vercel.app/index.html)
